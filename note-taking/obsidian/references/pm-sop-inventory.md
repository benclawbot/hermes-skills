## Quick Wins (Tier 1 SOPs, highest leverage)

These can be automated immediately with minimal setup:

1. **Status Report drafting** → hook into Linear/Jira/Trello, auto-generate for PM review
2. **Meeting note summarization** → standup/sprint review → action items drafted
3. **Burndown/Velocity charts** → auto-generated from task system
4. **EVM metrics calculation** → auto from timesheet + task data
5. **Risk Register drafting** → from WBS + project type pattern library
6. **Change Request logging** → from email/chat input
7. **Project archiving** → auto-file and compress closed project docs

## Tier 2 Priority (AI drafts, human refines)

1. Sprint planning prep — velocity history + capacity + backlog priority
2. Project Charter / Business Case drafts
3. Communication Plan drafts
4. Lessons Learned drafts (from retrospective data)
5. Sprint goal drafts (from backlog context)
