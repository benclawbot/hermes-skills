## Strategy Definitions
- **Mitigate**: Take action to reduce probability or impact
- **Transfer**:转移 - outsource or insure the risk
- **Avoid**: Eliminate the cause entirely
- **Accept**: Acknowledge and prepare to handle if occurs

## Action Checklist
- [ ] Action defined clearly
- [ ] Owner assigned
- [ ] Trigger conditions specified
- [ ] Deadline set and realistic
- [ ] Resources allocated

## Trigger Types
- Time-based (calendar event)
- Event-based (something occurs)
- Threshold-based (metric reaches level)

## Review Schedule
- Weekly status review
- Trigger condition monitoring daily
