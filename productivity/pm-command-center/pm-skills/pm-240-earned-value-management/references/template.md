## Forecasting

### Estimate at Completion (EAC)

| Method | Formula | Estimate |
|--------|---------|----------|
| Typical (AC + (BAC - EV)) | AC + (BAC - EV) / CPI | |
| Best Case (AC + remaining work at budget rate) | AC + (BAC - EV) | |
| Worst Case (AC + remaining work at current rate) | AC + (BAC - EV) / CPI | |

### To Complete Performance Index (TCPI)

| Metric | Value |
|--------|-------|
| TCPI to meet BAC | (BAC - EV) / (BAC - AC) |
| TCPI to meet EAC | (EAC - EV) / (EAC - AC) |
