# PM-140: Communication Planning Template

## Overview
This template defines the communication strategy for stakeholders throughout the project.

## Communication Plan

| Stakeholder | Message | Frequency | Channel | Format | Owner |
|-------------|---------|-----------|---------|--------|-------|
| Project Sponsor | Status update, blockers, decisions | Weekly | Email | Report | PM |
| Project Team | Sprint goals, assignments | Daily | Teams/Slack | Briefing | PM |
| Steering Committee | Progress, risks, decisions | Bi-weekly | Meeting | Presentation | PM |
| Business Owner | Requirements, demos | As needed | Email/Meeting | Documentation | PM |
| External Vendors | Deliverables, issues | Weekly | Email | Report | PM |

## Channel Definitions
- **Email**: Formal written communication
- **Meeting**: Synchronous discussion
- **Slack/Teams**: Quick informal updates
- **Report**: Formal documented update

## Format Types
- **Report**: PDF or Word document
- **Presentation**: Slides with talking points
- **Briefing**: Short verbal or instant message
- **Documentation**: Technical specs or requirements

## Communication Principles
1. Right information to right people at right time
2. Use appropriate channel for message type
3. Document all formal communications
4. Confirm receipt for critical messages

## Status Meeting Cadence
- Daily Standup: 15 min, same time each day
- Weekly Status: 30 min, same day each week
- Monthly Review: 60 min, executive stakeholders
